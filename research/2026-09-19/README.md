# Research snapshot: 2026-09-19

34 annotated sources supporting Chtets development. Read [the corpus](Chtets_Annotated_Corpus_EN.md) or use [corpus.jsonl](corpus.jsonl). Each card separates findings, limitations, candidate rules and test ideas. Exact reading locations and observed resource terms are included.

This snapshot is a targeted literature review, not a replicated experiment or proof of Chtets effectiveness. Related papers may reuse evidence; 34 sources are not 34 independent confirmations. Most empirical material is English. French register has limited direct coverage; Russian author-voice preservation remains a gap in this selection.

The files contain original annotations and primary links. They do not include papers, raw benchmark records or private author samples. Consult [resource-register.md](resource-register.md) before obtaining external data. Code licenses must not be assumed to cover underlying source texts.

[Methodology](methodology.md) and search logs record scope, exclusions, access failures and version differences. The snapshot describes the research-building stage; current implementation and evaluation status is maintained in [development](../../docs/development.md) and [evaluation](../../docs/evaluation.md).

This directory belongs to the source archive. It is not included in the installable skill or injected into writing prompts.
