# Changelog

## 1.0.0 — 2026-09-19

Initial English public release.

- Portable writing and editing workflow with six focused reference guides.
- Separate checks for factual meaning, composition, and language.
- Genre guidance for correspondence, commentary, explanations, reports, UI copy, and fiction.
- Optional author profiles with no personal defaults in the public skill.
- Installation documentation for Agent Skills clients and a complete prompt for other chat apps.
- Synthetic examples, research notes, validation, and reproducible ZIP packaging.

The earlier personalized Russian prototype is the source of the editorial approach. This release generalizes that material; it does not inherit a proven performance claim.
